CargoTwin

Real-time cargo monitoring using embedded sensors, MQTT telemetry, and a browser-rendered 3D digital twin. Built on ESP32 with MPU6050 and NEO-6M GPS hardware.

// 01
Project Overview

CargoTwin is an end-to-end IoT platform for monitoring the physical integrity of cargo shipments in real time. An ESP32 microcontroller mounted on a shipping container continuously samples a 6-DOF inertial measurement unit and a GPS receiver, publishing telemetry at 20 Hz over MQTT.

The browser dashboard renders a live 3D digital twin of the container that mirrors orientation in real time — driven by raw roll, pitch, and yaw from the MPU6050 — and overlays GPS position on a Leaflet.js map.

Shock and tilt events are detected on-device and in-browser, stored in flash memory, and replayed on the 3D twin with incident markers on the map. Impact force is calculated in Newtons from the actual cargo weight the user sets on a slider.

A route progress bar tracks the shipment from Port of Shanghai to Port of Los Angeles, showing completion percentage, remaining distance, and ETA from live GPS speed.

Hardware Stack
ESP32-WROOM-32Microcontroller
Dual-core 240 MHz Xtensa LX6 MCU with built-in Wi-Fi (802.11 b/g/n). Runs the MQTT publisher, sensor fusion loop, and incident detection at 20 Hz. Flash storage used for buffering events during connectivity loss.
240 MHz 520 KB SRAM Wi-Fi
MPU60506-DOF IMU
3-axis gyroscope (±2000 °/s) and 3-axis accelerometer (±16 g) on a single chip. Communicates via I²C at 400 kHz. Provides raw acceleration vectors for tilt angle, g-force magnitude, roll, pitch computation, and shock detection.
I²C 400 kHz 16-bit ADC 0x68
u-blox NEO-6MGPS Receiver
50-channel GPS receiver parsing NMEA GPGGA/GPRMC sentences at 1 Hz over UART at 9600 baud. Provides latitude, longitude, speed (km/h), course, satellite count, and fix status. 2.5 m CEP accuracy in open-sky conditions.
2.5 m CEP UART 9600 1–5 Hz
Mosquitto BrokerMQTT Middleware
Standards-compliant MQTT broker running locally or in the cloud. The dashboard connects via MQTT over WebSocket on port 9001. Subscribes to shipment/# for telemetry, event, and config packets.
WS :9001 QoS 0
// 03
Software Stack
Three.js3D Digital Twin
WebGL-rendered ISO 20ft shipping container with procedural ribbed textures and weathering. Orientation updated at 20 Hz. Supports orbit, ISO, side, end, and top camera views. Incident replay ghosts appear as red transparent overlays at the moment of impact.
WebGLr148
Leaflet.jsGPS Map
Lightweight interactive map with ESRI dark-grey tile layer. Plots live GPS track polyline, incident markers (red = tilt, amber = shock), origin / destination pins, and a dashed route reference line between Port of Shanghai and Port of Los Angeles.
v1.9ESRI tiles
MQTT.jsBroker Client
Browser-native MQTT over WebSocket library. Handles auto-reconnect every 2 s and routes incoming messages — telemetry {t:"d"}, events {t:"e"}, config {t:"cfg"} — to the correct handlers with zero polling.
WSAuto-reconnect
Telemetry PipelineVanilla JS
Zero-dependency dashboard logic: incident detection, force calculation (F = m · g · a), Cargo Integrity Score, route progress via haversine distance, CSV export, rolling time-series chart on Canvas, and Web Audio API alerts for shock events.
Zero depsCanvas API
